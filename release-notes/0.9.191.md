### Behaviour changes

- **Switches that run during free power.** A new `free_power_loads` list in `config.yaml` (for example `switch.immersion_heater`) is turned on when an EDF free-electricity session starts and off when it ends, in Active mode only. A switch already on is left alone and one you turn off yourself stays off for that session. The Config page doesn't edit the list yet but keeps it when saving. See docs/SITE.md.

### Behind the scenes

- `pe_core/freeloads.py` holds the on/off rules (the same ones as the heating set-back); state is kept in `free_loads.json`.
