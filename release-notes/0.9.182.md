### Behaviour changes

- **A summary when a grid event ends.** When an event is over, the Alexa speakers say how it went: what the house used, what was exported, and what the event should pay (and the figure after the battery energy it used). If PowerEngine switched anything for the event, it says what was turned back and to what, so it is clear whether each thing is now on or off: "The heating set-back is back to off, as it was before, so the heating is back on its programme", "The car charger is back to Eco+, as it was before". Where it left something alone it says so ("The heating set-back was already on before the event, so I've left it on", "The car charger mode was changed during the event, so I've left it as it is").
- **Same speakers, opening words and quiet hours as the other announcements.** An event that ends after the latest time (the default 21:00) is kept and spoken in the morning ("The grid event at 8 pm yesterday is over"), unless it is more than 14 hours old. Switch it off with "Announce a summary when a grid event ends" in the Announcements section of the Config page (on by default; the Alexa announcements switch must be on too). This release includes the card that adds it; an older card is warned about.

### Behind the scenes

- `announce.event_summary` and `announce.finish_message`; `Setback.note` and `CarStop.note` record what happened for an event; the event being followed is kept in `event_run.json` so a restart loses nothing. Tests in `tests/test_event_finish.py`.
