### Behaviour changes

- **The Predbat handover is gone.** PowerEngine no longer ships or installs `powerengine_predbat_handover.yaml` (the
  Predbat/PowerEngine switch), the dashboard no longer has the Battery controller panel, and *Other battery controller*
  has two choices, *No other battery controller* and *Another controller* (a saved *Predbat* from an older version is
  read as *Another controller*). A Predbat package file an earlier version put in your `packages` folder is removed the
  next time PowerEngine starts (a backup is kept), then press **Load PowerEngine's Home Assistant changes**. The
  handover guards, which stop PowerEngine writing while another controller is in charge, are unchanged, and the Config
  page no longer suggests the Predbat switch for them.
- **The retired `remove_entities` setting** (the AppDaemon app's uninstall switch) is ignored if it is in a saved config.
- **Package backups are capped.** Of the handover package's `.bak-<date>` files only the newest three are kept.

### Behind the scenes

- The install guide's Predbat sections (switching, one-off setup, removing, switching back) are replaced by a plain
  "set up, test, go live" walk-through. The demo's stand-in for another controller is named "other battery control".
