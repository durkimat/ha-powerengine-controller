### Behaviour changes

None. This release only renames files; nothing PowerEngine does changes.

### Behind the scenes

- **The engine's source folder is `engine/`** (it was `apps/powerengine`, from when PowerEngine was an AppDaemon app).
  `custom_components/powerengine/engine/` is still the copy the integration carries (generated by
  `tools/build_integration.py`). Paths in the tools, tests, CI path filters, `pyproject.toml` and the docs follow.
- **The dashboard template is `engine/dashboard/dashboard.yaml`** (it was `dashboard.lovelace`) and the Solis inverter
  definition is `engine/pe_core/adapters/devices/solis.yaml` (it was `solis.yml`). Both extensions existed only so that
  AppDaemon would not load them as app configuration. A definition file is now `devices/<name>.yaml`; the loader reads
  every `devices/*.yaml`. The test that kept stray `.yaml` out of the engine's folder now checks that the only YAML the
  engine ships is the dashboard and the definitions.
- The frozen copy of the rendered dashboard in `tests/golden/` is `.yaml` too.
- The simulator's "compare against a git ref" still works for refs from before this rename: it exports `apps/powerengine`
  from such a ref and presents it as `engine/` (`tools/sim/workspace.py`).
