### Behaviour changes

- **Settings that no longer exist are refused, by name, instead of being ignored.** `system.publisher` (gone with MQTT in
  0.9.214) and the top-level `remove_entities` (an old uninstall switch) were accepted and ignored so that an old
  settings file kept loading. A file that still has either now fails to load with a message naming it: delete the line.
  (The owner's file had `publisher: auto`; it was removed, with a backup, before this release.) The Config page no longer
  has a row for `publisher` and does not send `remove_entities`.
- **The card is Apache-2.0 like the rest of the repository.** `card/LICENSE` (MIT) is removed now that the card lives here
  and ships in the integration; the repository's `LICENSE` covers everything in it.
- Inverter-clock hints name no particular inverter's entities: the dashboard's note ("Map *Inverter clock* and *Sync
  inverter clock*...") and the drift message ("press your inverter's sync-clock button") speak generally. A few comments
  that used one integration's entity names as examples do the same.

### Behind the scenes

- Tests: a setting that no longer exists is refused by name (`tests/test_config.py`); the Config page topic test no longer
  special-cases `publisher`; the frozen dashboard copy follows the hint.
- The engine comparison and the simulator drop `publisher` and `remove_entities` from an archived owner config before a
  replay (older archives still hold them), so replays of old days keep working.
