### Behaviour changes

- **A new install shows the demo by itself.** Add the integration (it now asks nothing) and open *Power Engine*: a simulated
  home and battery runs one recorded day, with every page filled in. Pick another day from the banner, or **Exit demo**; once
  you have left it, it does not start by itself again. It never starts once PowerEngine has a configuration, and it controls
  nothing. Your own install is unchanged.
- **The Shadow mode is gone.** It existed to compare the new integration with the old AppDaemon one during the move, which is
  finished. The setup form no longer asks for a mode, and the `refresh_shadow` service is removed. Your existing entry keeps
  working.

### Fixes

- **The demo works under the integration.** It was broken there: the engine could not see the simulated home ("28 required
  inputs not ready") and the demo's entities went unavailable. Both are fixed, and a test now starts, changes and leaves the
  demo against real Home Assistant.
- The demo's day change and start take a few seconds, not "about a minute", and "Try the demo" is no longer offered while the
  demo is running.

### Behind the scenes

- The install guide starts with a three-step "Just want to look first?" and no longer mentions the mode choice.
