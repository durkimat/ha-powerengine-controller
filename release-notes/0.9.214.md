### Behaviour changes

- **MQTT publishing is gone.** PowerEngine's entities are the integration's own entities (or, in the demo and the
  tests, plain states); the engine no longer has an MQTT publisher, MQTT discovery or the AppDaemon MQTT plugin lookup,
  and nothing about PowerEngine needs a broker. The entity ids, unique ids, names and values are unchanged.
- **The *Entity publishing* setting (`system.publisher`) is removed** from the Config page. A saved config that still
  has it (`auto`, `mqtt` or `direct`) loads as before: the setting is ignored.
- The shadow run no longer rewrites the copied config's publishing setting, since there is none.

### Behind the scenes

- `entities.py` no longer builds topics or discovery payloads (`discovery_payload`, `removal_messages`, the topic
  constants and the `command_topic`/`state_topic` options are gone); `select_publisher` chooses between the native and
  plain-state publishers by what the host offers. The replay safety net (`tests/test_replay.py`) passes unchanged: the
  fake Home Assistant now sees the engine's pause switch as a state write instead of an MQTT message.
