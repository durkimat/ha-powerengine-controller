### Behaviour changes

- **A grid event now counts only the part of each half-hour it really covered.** Before, one reading at the very edge of an event made the whole neighbouring half-hour an event one. On 1 Nov 2026 that put 2 kWh sold on the ordinary schedule before the event into it (PowerEngine said 5.66 kWh and £6.50; Axle paid £3.78), and on 6 Oct it counted 0.13 kWh from before an event that exported nothing. The recorder now keeps the seconds the event ran in each half-hour (`axle_s`); a half-hour with under 3% of the event in it is not part of it, and one partly in it counts that part of its export. The costs are re-valued once on the first start (method 9).
- **What the event pays and the export rate are shown apart.** The event pays £1 a kWh exported; EDF's export rate on top is a separate payment from EDF. The grid event summary now says "The event should pay about £3.26, and the export rate adds about £0.49, or £3.50 in all after the battery energy it used". The last-event line on the dashboard, the events table and the Costs page need card 0.9.200 for the same split.
- The dashboard's key now explains the two ("Axle pays", "Export rate on top").

### Behind the scenes

- Cost records carry `axle_s`; `costs.event_share`, `event_pay` and `event_export` per half-hour, `pay` in each event total, and `axle_pay` per month (and a last value in each listed day).
