### Behaviour changes

- **Predbat and AppDaemon leftovers are removed from the engine.** A saved `other_controller: predbat` (a choice that
  went in 0.9.213) is no longer quietly read as `other`: choose *No other battery controller* or *Another battery
  controller* on the Config page. The engine also no longer recognises or removes a `powerengine_predbat_handover.yaml`
  package file (it has not been shipped since 0.9.211).
- The Status sensor's text when inverter writes cannot be confirmed now says control stays stopped "until the engine
  restarts" (it said AppDaemon).
- The install guide, the integration notes and the other docs no longer describe AppDaemon, MQTT or Predbat; the
  integration README no longer describes a "another PowerEngine is running" check that was removed earlier.

### Behind the scenes

- **The release tooling is one repository's now.** `tools/release.sh`, `tools/prepare_release.sh`, `release.yml` and
  `docs/RELEASING.md` lose the separate card release (`--card-notes`, `--card-branch`, `--card-dir`, the workflow's
  `card_branch` and `card_notes`): the card is in this repository and goes out with every release. `release.sh` runs the
  card's node tests with the app's checks, and `tools/outline.sh card` reads `card/`.
- The retired `ha-powerengine-card` repository is archived (its README says where the card went).
- The stray CI workflow inside `card/` is removed (the repository's CI runs the card's tests and HACS validation), and
  the card's notes and README describe the bundled card as it is now.
- Comments and docstrings describe the host as it is (the engine's own process) instead of AppDaemon; the files that
  were named `.yml` / `.lovelace` to keep AppDaemon from loading them no longer say so.
