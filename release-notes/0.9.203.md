### Behaviour changes

None. This release adds pieces that nothing in a running system uses yet.

### Behind the scenes

- The engine can now run as its own process, without AppDaemon: its own timers (`run_in`, `run_every`, `run_daily`)
  and the single thread its callbacks run on, a local connection to Home Assistant with a shared secret and a versioned
  protocol, and a copy of the states it has read so that reading stays instant. `apps/powerengine/engine_main.py` starts
  it. This is the second step towards updating the engine without restarting Home Assistant (plan:
  `docs/plans/native-integration.md`).
- New tests put the same questions to the AppDaemon host and the new host, check the handshake and reconnection, and
  start the real engine as a real process against a stand-in for Home Assistant.
- Under AppDaemon nothing changes: it still uses `AppDaemonHost`, and none of the new code is loaded.
